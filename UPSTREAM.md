# Upstream and independence

Lumeweft is an independent community fork derived from
[Velorn](https://github.com/VelornLabs/velorn). It is not affiliated with,
endorsed by, or supported by VelornLabs or the Velorn project.

The original copyright notices and GPL-3.0-only license are preserved. Git
history remains available so the origin and evolution of the code can be
audited. Compatibility identifiers that still contain `velorn` or
`comfystudio` may remain temporarily where changing them would break existing
projects, integrations, or stored settings.

Lumeweft-specific support requests and bug reports should be directed to the
Lumeweft fork, not to the upstream Velorn maintainers.
