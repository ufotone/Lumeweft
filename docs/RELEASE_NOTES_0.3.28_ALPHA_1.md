# Lumeweft 0.3.28 Alpha 1

This is the first public alpha preview of Lumeweft.

## Download

- Windows x64 installer only
- macOS and Linux are not tested, distributed, or supported in this release
- This alpha build is currently unsigned and Windows SmartScreen may display a warning

## Highlights

- Community model browsing and guided Civitai model/LoRA workflows
- CANVAS visual workflows with image/video-to-prompt support through MiniMax H3 Promptor
- Generation history, prompt reuse, workflow import, repair, and artifact export tools
- Automatic import of outputs generated in the embedded ComfyUI workspace
- Guided Music Video, Short Film, UGC, and Business Ad workflow improvements
- Expanded Japanese localization and lightweight static effect previews

## Important notes

- Lumeweft is alpha software and may contain incomplete features or breaking bugs.
- Generation features require a separately installed local ComfyUI instance and may require additional models or custom nodes.
- Third-party models, nodes, and services remain subject to their own licenses and terms.
- This release is provided without support or warranty.
