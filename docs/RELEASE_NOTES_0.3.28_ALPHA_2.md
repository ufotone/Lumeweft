# Lumeweft 0.3.28 Alpha 2

This alpha updates the Windows build with expanded CANVAS workflows, Lumeweft branding, and safer first-run defaults.

## Download

- Windows 10/11 x64 installer only
- macOS and Linux are not tested, distributed, or supported in this release
- This alpha build is unsigned and Windows SmartScreen may display a warning

## Highlights

- Added a CANVAS MiniMax H3 GGUF Image-to-Video workflow with native audio support.
- Added a CANVAS Start Frame / Last Frame workflow for generating video from two reference images.
- Added guided setup checks for the required ComfyUI custom nodes and model files.
- Added CANVAS reload and recovery controls for failed or stuck workspace rendering.
- Replaced remaining visible Velorn branding in the Windows app, installer, and timeline controls with Lumeweft branding.
- Hid the upstream feedback link, shortened the MCP label, and changed first-run defaults so ComfyUI does not launch automatically and no launcher script is preconfigured.

## Important notes

- Lumeweft is alpha software and may contain incomplete features or breaking bugs.
- Generation features require a separately installed local ComfyUI instance and may require additional models or custom nodes.
- MiniMax model weights, ComfyUI custom nodes, and other third-party components remain subject to their own licenses and terms.
- This release is provided without support or warranty.
