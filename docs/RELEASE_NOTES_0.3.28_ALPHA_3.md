# Lumeweft 0.3.28 Alpha 3

This alpha expands Lumeweft's guided generation workflows, cloud-runtime integration, voice tools, and generation-result management.

## Download

- Windows 10/11 x64 installer only
- macOS and Linux are not tested, distributed, or supported in this release
- This alpha build is unsigned and Windows SmartScreen may display a warning

## Highlights

- Expanded the CANVAS and Workflow Setup catalogs with additional image, video, audio, captioning, interpolation, and upscaling workflows.
- Added guided cloud-runtime support with secure local credential storage and clearer API-key setup.
- Added Irodori voice-cloning production tools and improved audio-result presentation.
- Added safer deletion for completed generation results, related history records, project assets, and owned local output files.
- Updated local-first GGUF workflow presets and dependency guidance for Qwen Image, WAN 2.2, MiniMax H3, LTX-Video, and related workflows.
- Improved generation-library, recipe, Director, project-asset, localization, and recovery behavior across the app.

## Important notes

- Lumeweft is alpha software and may contain incomplete features or breaking bugs.
- Generation features require a separately installed local ComfyUI instance and may require additional models or custom nodes.
- Cloud workflows require the relevant third-party account, API key, credits, and acceptance of that provider's terms.
- Model weights, ComfyUI custom nodes, cloud services, and other third-party components remain subject to their own licenses and terms.
- This release is provided without support or warranty.
